# doc/history/

Design records from February to April 2026, kept for provenance and not
maintained: they describe the supervised trainer that preceded the
active-learning loop, the plan for the first transformer loop, the port of the
GP pipeline from the `al_pmssmwithgp` submodule and the harmonisation of the
two into the `pmssm` package. File names, flags and layouts in them refer to
the repository as it was then; the current documentation is one level up.
